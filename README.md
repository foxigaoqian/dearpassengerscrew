# Dear Passengers Crew

Independent multilingual game-intelligence website for **Dear Passengers**.

## What is included

- Six localized editions: English, Simplified Chinese, Japanese, Arabic, Turkish and Ukrainian
- Official Steam media and official trailer embed
- Verified release/platform/demo status board
- Player-intent FAQ content
- Interactive crew compatibility checker
- SEO essentials: canonical URLs, hreflang, JSON-LD, sitemap and robots
- Responsive layout for desktop, tablet and mobile

## Development

```bash
npm install
npm run check
npm run dev
```

## Deployment

```bash
npm run deploy
```

The production routes are configured in `wrangler.jsonc` for:

- `dearpassengerscrew.com`
- `www.dearpassengerscrew.com`
